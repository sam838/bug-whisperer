Kane works one case at a time, in a real Chrome browser. A visit to the scene takes about 2 minutes.

1 · The case

Claude reads the complaint and the screenshot, and works out what the user did.

2 · The scene

Kane retraces the user's steps in a real browser and captures every screen.

3 · The evidence

Kane checks what the user claimed. A memory or a guess doesn't count.

4 · The repair

If the code is connected, Claude fixes it, using only Kane's evidence.

5 · Case closed

Kane repeats the exact steps. Only a pass closes the case, and it stays on file.
